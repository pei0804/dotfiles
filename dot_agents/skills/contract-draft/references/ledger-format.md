# 交渉台帳フォーマット

台帳は契約交渉の状態を1ファイルに集約する。目的は2つ。「経緯を踏まえた修正案」を、やり取り全読みではなく1ファイル読みで作れるようにすること。新しい版を受け取ったとき、何が反映されるべきかの突合対象を持つこと。

## 置き場

作業リポジトリに置く。プロジェクトにドキュメント規約（knowledge ディレクトリ等）があればそれに従う。交渉中は台帳として更新し、締結時に「締結記録」へ昇格させる。昇格時は論点表を「論点ごとの決着」に、conceded の一覧を「承知のうえで受けている点」に書き換えるだけでよい。

## 状態と遷移

| 状態 | 意味 |
|---|---|
| open | 論点として認識した。まだ方針がない |
| drafting | こちらで修正案を検討中 |
| proposed | 修正案を相手方へ送付済み。反映待ち |
| reflected | 新しい版で反映を確認した |
| countered | 相手方から対案が来た。評価が必要 |
| conceded | こちらが飲んだ。**理由の記載が必須** |
| closed | 決着した（reflected または conceded を経て） |

論点のボール（いま誰の判断・作業待ちか）は確認・依頼キューから導出する。キューに宛先別の未回答項目があれば、その宛先がボールを持っている。

## 確認・依頼キュー

交渉は3者以上（自分・社内法務・相手方の担当者・相手方の法務）で同時並行に動く。論点の実質とは別に、通信の状態をキューで持つ。

| ID | 宛先 | 関連論点 | 内容 | 状態 |
|---|---|---|---|---|
| Q1 | 相手方担当者 | 2 | 実装まで含むかの実態確認 | 送付済み {日付} |
| Q2 | 社内法務 | 3, 5 | 権利帰属の建付け確認（飲む点は先出し済み） | 回答済み |
| Q3 | 相手方法務 | 2 | 不具合対応の条文案 | 未送（待ち: Q1） |

状態は「未送 → 送付済み → 回答済み」。回答が来たら要旨を論点詳細へ転記して消し込む。

キューの運用ルール。

- **宛先が違う確認は互いを待たない。** 並行が既定。待つのは依存があるときだけで、依存は「待ち: Q◯」と明示する（例: 条文提案は契約類型の実態確認待ち）
- **送信は宛先ごとに flush する。** 未送の項目を宛先ごとにまとめて1通にする。宛先の社内往復を1回で済ませるため
- 宛先の決め方: 実態・業務範囲・意図 → 相手方担当者。建付けの妥当性・リスク許容 → 社内法務。条文の文言 → 相手方法務（担当者経由で条文案を渡す）

## テンプレート

```markdown
---
title: "{契約名} 交渉台帳"
status: negotiating   # negotiating → concluded
---

# {契約名} 交渉台帳

## 契約の骨格

| 項目 | 内容 |
|---|---|
| 契約類型 | {準委任 / 成果物が生じる準委任 / 請負} |
| 当事者 | {甲・乙} |
| 期間 | |
| 対価 | |
| 現在の版 | rev{N}（{受領日}） |

## 論点表

| ID | 論点 | 状態 | ボール | 最終更新 |
|---|---|---|---|---|
| 1 | {例: 権利の帰属} | proposed | 相手方 | rev2 送付時 |

## 確認・依頼キュー

| ID | 宛先 | 関連論点 | 内容 | 状態 |
|---|---|---|---|---|
| Q1 | {社内法務 / 相手方担当者 / 相手方法務} | 1 | {内容} | {未送 / 送付済み◯月◯日 / 回答済み}（依存があれば 待ち: Q◯） |

## 論点詳細

### 1. {論点名}

経緯を時系列で。各行に「誰が何を」を書く。

- rev1: {現状の条文の要点}。{誰}が{何を}指摘
- {日付}: 提案パケット送付（下記）

送付した提案パケットをそのまま貼る。次版の反映確認の突合対象になる。

## 承知のうえで受けている点（conceded）

条項ごとに、何を・なぜ飲んだかを1段落で。

## 事務項目

締結日欄、表記統一、締結方式、送付先などの実質論点でないもの。

## 次の契約に引き継ぐ論点

今回入れなかったが、次の契約・覚書で検討するもの。
```

## 更新規則

- FB を受けたら、修正案を書く前にまず台帳へ落とす
- 版を受領したら contract-check の結果で状態を進める（proposed → reflected / countered）
- conceded には必ず理由を書く。理由のない譲歩は後で再交渉の判断ができない
- 版が変わって条番号がずれたら、論点詳細の条番号を最新版基準に直し、旧番号を併記する
